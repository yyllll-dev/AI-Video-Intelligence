## 一、这是什么

一个**学习视频智能记忆系统**的界面：摄像头/视频拍到学习过程，系统识别事件、用 AI 理解、存成记忆，用户用自然语言搜索并回放。界面用 **Gradio** 构建，白底蓝色主题，SVG 图标。

界面要能展示的链路（对齐团队「明日任务安排」PDF 验收标准）：

```
视频/画面 → 当前检测到的人 → 当前事件 → 事件时间 → VLM 分析结果 → 历史事件记录 → 自然语言检索
```

## 二、目录结构

```
demo/
├── app.py          # 界面主文件（UI 布局 + 回调 + 样式）
├── README.md       # 本文档
└── core/           # ★ 全新内容单独成文件夹：核心常量 + 模拟数据
    ├── __init__.py     # 汇总导出，app.py 从这里 import
    ├── events.py       # 14 种事件映射 + 物体类别映射（中英文对照）
    └── mock_data.py    # 模拟各后端模块输出（假数据占位）
```

**为什么拆出 `core/` 文件夹**：事件映射和模拟数据是「全新的、可复用的内容」，与 `app.py` 的 UI 布局职责分离。这样：

- 事件名/类别映射统一放一处，全组对齐、避免各写各的。
- 模拟数据集中管理，接入真实后端时只需替换 `core/mock_data.py` 里的函数，`app.py` 一行都不用改。

## 三、14 种事件体系（核心对齐）

这是本版最重要的变化。团队「明日任务安排」PDF 明确要求：**全组统一使用 14 种事件名，不要再出现不同模块使用不同事件名的情况**。

`core/events.py` 里的完整对照表：

| 英文事件名（跨模块通信用） | 中文显示名（界面用） |
|---|---|
| `sit_at_study_position` | 坐到学习位置 |
| `leave_study_position` | 离开学习位置 |
| `study_preparation` | 学习准备 |
| `start_study` | 开始学习 |
| `end_study` | 结束学习 |
| `reading` | 阅读 |
| `writing` | 写字 |
| `phone_learning` | 手机学习 |
| `computer_learning` | 电脑学习 |
| `other_study_behavior` | 其他学习行为 |
| `phone_distraction` | 手机分心 |
| `computer_distraction` | 电脑分心 |
| `communication_distraction` | 交流分心 |
| `study_end_cleanup` | 学习结束整理 |

> ⚠️ 注意：早期版本曾用过 `phone_usage`、`open_book` 等事件名，现已**废弃**，统一使用上表 14 种。

**物体类别映射**（检测结果 `class_name` → 中文）也在 `core/events.py`：

| class_name | 中文 |
|---|---|
| `person` | 人 |
| `book` | 书 |
| `pen` | 笔 |
| `cell phone` / `phone` / `mobile phone` | 手机 |
| `laptop` / `computer` | 电脑 |

## 四、界面布局与各区域说明

```
┌──────────────────────────────────────────────────────────┐
│  [logo]  AI 学习记忆                                      │  ← 顶部标题
│         AI Learning Memory · 实时视频智能分析              │
├────────────────────────────────┬─────────────────────────┤
│  ─ LIVE VIDEO 实时画面        │  ─ 当前事件 Current Event │
│  [实时摄像头 | 本地视频文件]     │  ┌─────────────────────┐ │
│                                │  │ 手机分心             │ │
│  [开始分析] [停止分析]  ●待机   │  │ phone_distraction…   │ │
│  ─ AI Analysis 分析           │  └─────────────────────┘ │
│  ┌──────────────────────────┐ │  ─ 历史事件记录          │
│  │ 实时检测 [LIVE]           │ │  00:12 开始学习          │
│  │ 语义理解 [事件触发]        │ │  02:05 学生正在书写      │
│  └──────────────────────────┘ │  10:32 手机分心（当前）   │
├─────────────────────────────┴───────────────────────────┤
│  ─ 问问你的学习记忆                                       │
│  [搜索框____________________] [搜索]                      │
│  ─ 搜索结果（时间戳/事件/描述/视频片段）                     │
│  [回放选中片段]                                            │
└──────────────────────────────────────────────────────────┘
```

### 4.1 顶部标题
纯静态，标识系统身份（logo + 标题 + 副标题）。

### 4.2 LIVE VIDEO（视频输入）
- **显示**：Tab 切换「实时摄像头」/「本地视频文件」，用于采集画面。
- **运行**：这里只**采集画面**，点「开始分析」才启动分析。状态圆点：灰「待机」→ 绿「运行中」→ 灰「已停止」。
- 摄像头与文件本质都是「帧流」，区别仅在于时间轴（真实时间 vs 视频时间）。

### 4.3 AI Analysis（分析）
- **显示**：卡片分两段，各带徽章：
  - **实时检测 `LIVE`**：当前帧检测到的人/物，如「人 ×1 · 手机 ×1 · 书 ×1」。
  - **语义理解 `事件触发`**：VLM 生成的文字描述。
- **运行**（两条节奏）：上段由检测模型**逐帧**更新（跳动快）；下段由 VLM **事件触发**更新（命中事件才刷新）。徽章用来区分两者。

### 4.4 当前事件 Current Event
- **显示**：当前正在发生的事件卡片：中文事件名、英文 key、track 编号、置信度、起止时间。
- **运行**：由事件引擎输出，随播放/时间推进实时切换。

### 4.5 历史事件记录（★ 本次新增）
- **显示**：本次会话已发生事件的累积列表，格式「时间 + 事件」，最后一条高亮标「当前」。
  ```
  00:12  开始学习
  02:05  学生正在书写
  10:32  手机分心（当前）
  ```
- **运行**：摄像头随真实时间持续追加；视频文件边播边生成。

### 4.6 搜索区「问问你的学习记忆」
- 自然语言搜索框 + 「搜索」按钮，回车或点击触发检索。

### 4.7 搜索结果 + 回放
- 整块表格（时间戳 / 事件 / 描述 / 视频片段），点击任意行 = 选中整条结果，再点「回放选中片段」播放对应片段。

## 五、数据从哪来（mock 说明）

当前界面**尚未接入真实后端**，所有数据来自 `core/mock_data.py`，每个函数对应一个后端模块的输出：

| mock 函数 | 对应后端模块 | 返回内容 |
|---|---|---|
| `mock_detections()` | A（Detection/Tracking） | 当前帧检测到的人/物 |
| `mock_current_event()` | A（EventEngine） | 当前事件 |
| `mock_timeline()` | A（EventEngine） | 历史事件记录列表 |
| `mock_vlm_result()` | B（Qwen-VL） | 语义理解文字 |
| `mock_search(query)` | D（Retrieval） | 检索结果 |

**接入真实后端的方法**：明天联调时，把 `app.py` 顶部的 `from core import mock_xxx` 换成对 `src/` 真实模块的调用（或直接改写 `core/mock_data.py` 里的函数），UI 层无需改动。

## 六、如何运行

```bash
# 1. 进入环境（Python 3.11）
conda activate multimodal

# 2. 绕过本机代理（否则 localhost 健康检查会 502）
#    Windows PowerShell：
#    $env:NO_PROXY = "127.0.0.1,localhost"

# 3. 启动
python demo/app.py
```

## 八、技术备注

- **框架**：Gradio 6.x，Python 3.11（`multimodal` 环境）。
- **图标**：内联 SVG（Lucide 风格），无 emoji。
- **视觉**：白底 + 蓝色点缀（`#2563eb`），卡片化布局，等宽数字。
- **事件字段规范**（对齐 `src/event/schemas.py`）：检测结果字段为 `class_name`（不是 `class`），事件字段为 `event_type / start_time / end_time / track_id / confidence / description`。
